# CMC 3D Prints

Web instalable que muestra la aplicación existente de Google Apps Script.

Pedidos, estadísticas, gastos, calculadora y stock se gestionan en la aplicación original. Se necesita conexión a internet. El service worker guarda únicamente los recursos de la parte instalable; no almacena pedidos ni fotografías.

Publicación: GitHub Pages desde main, carpeta raíz.
